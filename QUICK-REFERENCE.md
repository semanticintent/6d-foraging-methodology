## The 3D Lens Scoring

| Lens | Name | Measures | Question |
|------|------|----------|----------|
| Sound | ChirpIQX | Urgency | How immediate? (1-10) |
| Space | PerchIQX | Scope | How widespread? (1-10) |
| Time | WakeIQX | Trajectory | Getting better or worse? (1-10) |

**Formula:**
```
Dimension Score = (Sound × Space × Time) ÷ 10
```

**Score Interpretation:**

| Range | Level | Action |
|-------|-------|--------|
| 0-10 | Low | Monitor |
| 11-30 | Moderate | Investigate |
| 31-50 | Significant | Plan intervention |
| 51-70 | High | Immediate action |
| 71-100 | Critical | Crisis response |

## Common Cascade Patterns

**Revenue Spiral:**
```
Revenue ↓ → Layoffs → Quality ↓ → Customers leave → Revenue ↓↓
```

**Talent Drain:**
```
Uncertainty → Key people leave → Knowledge loss → Quality ↓
```

**Compliance Cascade:**
```
Finding → Remediation → Resource diversion → Delays → Customer impact
```

**Operational Ripple:**
```
System issue → Quality impact → Complaints → Revenue pressure
```

## Key Questions by Dimension

### Customer 👤
- What's the NPS trend?
- Churn rate changing?
- Support ticket volume?
- Social sentiment?

### Employee 👥
- Turnover rate?
- Engagement scores?
- Overtime trends?
- Exit interview themes?

### Revenue 💰
- Pipeline velocity?
- Payment terms extending?
- Deal sizes shrinking?
- Win rate declining?

### Regulatory ⚖️
- Open audit findings?
- Certifications current?
- Compliance gaps?
- Legal exposure?

### Quality ✨
- Defect rates?
- Rework percentage?
- Customer complaints?
- Warranty claims?

### Operational ⚙️
- Schedule variance?
- System uptime?
- Resource utilization?
- Backlog growing?

## Red Flags to Watch

| Signal | What It Might Mean |
|--------|-------------------|
| Multiple dimensions scoring >30 | Cascade in progress |
| One dimension >70 | Crisis imminent |
| L2 effects appearing | Cascade accelerating |
| Cross-dimensional jumps | Systemic issue |
| Scores increasing over time | Interventions not working |

## The Foraging Mindset

1. **Surface costs lie** — Always look deeper
2. **Problems cascade** — Follow the dominoes
3. **Dimensions connect** — Effects jump boundaries
4. **Time reveals** — L2/L3 take time to appear
5. **Quantify ranges** — Point estimates mislead
6. **The multiplier is real** — Usually 2-10×+
