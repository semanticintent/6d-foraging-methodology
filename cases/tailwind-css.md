## Key Insights

1. **AI-driven adoption paradox:** Product usage and revenue became inversely correlated. More developers use Tailwind than ever, but they never see the monetization path.

2. **Lifetime licensing as accelerant:** The Tailwind UI lifetime license model meant no recurring revenue to weather downturns. A subscription model would have provided stability.

3. **OSS sustainability crisis:** AI models trained on open source documentation now bypass the very monetization mechanisms that sustain OSS development.

4. **Community trust as hidden asset:** The llms.txt controversy revealed that reputational capital—built over years—can erode in days when the community feels betrayed.
